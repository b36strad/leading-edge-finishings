# PHP Hosting Deployment Layout

The project builds a static Astro site plus a PHP contact-form endpoint. The endpoint only runs on a PHP-enabled web host; GitHub Pages cannot execute PHP.

## Project Layout

```text
leading-edge-finishings/
├── public/
│   └── send-inquiry.php       # Copied into dist by Astro
├── private-config/
│   └── smtp-config.php        # Reads SMTP_PASSWORD from the environment
├── PHPMailer-master/
│   └── src/                   # PHP mailer library
└── dist/                      # Generated by pnpm build
```

Do not put `private-config/` or `PHPMailer-master/` inside `public/`. Astro copies files from `public/` into `dist/`; the private config and PHP library are intentionally excluded.

## Hosting Layout

Upload the **contents** of `dist/` to the PHP host's document root. For a host using `public_html`, the deployed layout should be:

```text
hosting-account/
├── public_html/                # Web root: upload the contents of dist/
│   ├── send-inquiry.php
│   ├── index.html
│   └── ...
├── private-config/
│   └── smtp-config.php
└── PHPMailer-master/
    └── src/
```

The PHP endpoint resolves `private-config/` and `PHPMailer-master/` as directories beside the web root. Keep both outside `public_html` so they cannot be requested directly from a browser.

## Deploy

1. Run `pnpm check` and `pnpm build` from the project directory.
2. Upload the contents of `dist/` to the PHP host's web root. Do not upload the `dist` directory as an extra nested directory.
3. Place `private-config/` and `PHPMailer-master/` beside the web root on the server.
4. Set the `SMTP_PASSWORD` environment variable in the hosting control panel or server configuration. Do not put the SMTP password in a committed file.
5. Confirm the host runs PHP and permits outbound SMTP over port 465, then submit a test inquiry and verify it arrives at the configured business inbox.
6. Set the production domain in `astro.config.mjs` before building the final deployment.

The Astro development server does not execute PHP. The contact form's fallback email link is available if the endpoint cannot be reached, but it is not a replacement for testing the PHP handler on the production host.

## Credential Note

The SMTP password that was previously stored in the project config was committed to Git history. Rotate that password; changing the working file alone does not remove the old value from existing commits.
